A GitHub-compatible git forge in pure Node with zero dependencies and no git binary. It serves git smart HTTP (upload-pack protocol v2 with a v0 fallback, receive-pack v0), the REST v3 API, GraphQL v4 and an MCP endpoint from one in-memory store, so a repository or issue created over one surface reads back unchanged over the others.

## Run it

```sh
node --experimental-strip-types main.ts
```
